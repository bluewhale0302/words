# 말결

발음이나 표기 일부만 기억날 때 한국어·영어·일본어 공개 사전 데이터를 바탕으로 가까운 단어를 찾는 웹 앱입니다.

## 주요 기능

- 한글로 적은 발음, 원어 표기, 단어 일부를 입력해 후보 검색
- 발음 유사도 70%, 표기 유사도 30%를 반영해 후보 순위 표시
- 결과를 5개, 10개, 15개 또는 전체로 보기
- 후보를 열어 발음, 한국어 뜻, 용법과 예문 확인
- 영어·일본어·한국어 결과의 언어와 국가 표시

유사도는 공개 사전의 표기와 발음 정보를 이용한 참고 점수입니다. 한글로 발음을 적는 방식, 억양 및 사전 데이터 범위에 따라 순위가 달라질 수 있습니다.

## 실행

1. [Node.js](https://nodejs.org/)를 설치합니다.
2. `말결 시작.bat`을 실행합니다.
3. 브라우저에서 `http://127.0.0.1:8000/`에 접속합니다.

로컬에서만 실행되며, 검색 시 공개 사전 서비스에 연결합니다. 검색 결과 일부는 사전 응답을 메모리에 보관해 반복 검색을 빠르게 합니다.

## 공개 데이터 및 서비스

- [Kaikki / Wiktionary](https://kaikki.org/dictionary/) — 표제어, IPA, 뜻, 활용형 및 예문 데이터
- [Datamuse API](https://datamuse.com/api/) — 영어 철자·발음이 가까운 후보
- [Jisho / JMdict](https://jisho.org/) — 일본어 표기, 읽기 및 뜻풀이

각 데이터의 저작권과 이용 조건은 원 제공처의 안내를 따릅니다. 검색 결과에 표시되는 사전 원문 링크에서 항목을 확인할 수 있습니다.

## 프로젝트 파일

- `index.html` — 검색 화면과 후보·단어 상세 화면
- `server.js` — 로컬 웹 서버와 공개 사전 API 연결 및 캐시
- `말결 시작.bat` — Windows 실행 파일
- `사용안내.md` — 한국어 사용자 안내

## GitHub에 올리기

이 폴더(`outputs`)를 GitHub 저장소의 루트에 올리면 됩니다. 이 환경에서는 Git 명령 프로그램을 사용할 수 없고, 연결된 GitHub 계정에는 말결 저장소가 아직 없으며 저장소 생성 도구도 제공되지 않아 직접 업로드는 완료하지 못했습니다. GitHub에서 새 저장소를 만든 뒤 `outputs` 폴더의 파일을 저장소에 업로드하면 됩니다.
